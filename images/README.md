# Imágenes para descarga

Esta carpeta contiene las imágenes pre-generadas que se descargan cuando el usuario hace clic en los botones de descarga.

## Archivos:
- `ramo-flores-amarillas.png` - Imagen PNG del ramo con mensaje (800x600)
- `wallpaper-flores-pc.png` - Fondo de pantalla para PC (1920x1080)
- `wallpaper-flores-mobile.png` - Fondo de pantalla para móvil (1080x1920)

## Beneficios:
- ✅ Descarga instantánea
- ✅ Sin problemas de CORS
- ✅ Mejor rendimiento
- ✅ Experiencia de usuario mejorada
