# Generar Imágenes para Descarga

Este directorio contiene el generador automático de imágenes para las descargas.

## Instrucciones:

### Opción 1: Usar el generador HTML
1. Abre `image-generator.html` en tu navegador
2. Haz clic en "Generar Imágenes"
3. Se descargarán automáticamente los 3 archivos
4. Mueve los archivos descargados a la carpeta `images/`

### Opción 2: Usar herramientas online
1. Ve a un convertidor SVG a PNG online (como convertio.co)
2. Sube el archivo `ramo-flores-amarillas.svg`
3. Descárgalo como PNG
4. Guárdalo en `images/ramo-flores-amarillas.png`

### Opción 3: Crear manualmente
Puedes crear las imágenes con cualquier herramienta de diseño y guardarlas como:
- `images/ramo-flores-amarillas.png` (800x600)
- `images/wallpaper-flores-pc.png` (1920x1080)  
- `images/wallpaper-flores-mobile.png` (1080x1920)

## Archivos requeridos:
- ✅ `images/ramo-flores-amarillas.png` - Imagen principal (800x600)
- ✅ `images/wallpaper-flores-pc.png` - Fondo PC (1920x1080)
- ✅ `images/wallpaper-flores-mobile.png` - Fondo móvil (1080x1920)

¡Una vez que tengas las imágenes, las descargas serán instantáneas! 🚀
